*// HOW TO USE *//

1. Upon opening the app, the user will be greeted by the front page of the product app.
2. On top is split into two section. The search section where user can enter manually the title of the product and a drop down current product will be available to select.
3. The second section is the refresh icon where user can click and it will refresh the page, calling the API again.
4. Below the search is the 'Tag' option where user can select up to all the available tag to filter the product further.
5. Lastly will be the product page which is a Grid 2x2 (30 total) view and each product is clickable. If user scroll all the way down, the next 30 batch of product is loaded.
6. Once click on the selected product, the product detail page will be presented and the user can view the product. There is a back button on top for user to return back to the product page.
